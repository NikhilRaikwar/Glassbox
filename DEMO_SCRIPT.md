# Glassbox video script — 2:40

## 0:00–0:15 — Hook

Show the landing page and say: “Students are learning to use AI. Glassbox teaches them how to challenge it.” Open Case 01 or show the Probe Lab. Compare Maya with an otherwise identical fictional profile in a different commute zone. Run the deterministic test and point out the exact score change on the receipt.

## 0:15–0:55 — Investigation

Pin the controlled receipt. Run or inspect a confirming controlled commute-zone comparison, then show the Evidence Notebook. Say: “The learner is not chatting for an answer. They are selecting reproducible receipts and making a claim.” Submit the hypothesis and show the claim–evidence map. If recording no-key mode, say clearly that the local deterministic coach is active; if recording with a configured key, show the GPT-5.6 coach response.

## 0:55–1:40 — Repair

Open Repair Bench. Say: “The evidence threshold gates the repair.” Remove the `Zone C penalty`, add the learning-relevant topic and collaboration signals, then run the eight-pair evaluation. Point to the computed equivalent-treatment rate, average match quality, affected-pair count, and exact deltas.

## 1:40–2:10 — Proof

Open Proof Card. Say: “This is a simulated model repair, not a fairness certification.” Show the selected receipts, hypothesis verdict, factor change, before/after measures, local educator peek, and download the working PNG proof card.

## 2:10–2:35 — Technical proof

Show `src/features/case-engine/` and explain that it controls scoring, receipt validity, evidence threshold, and evaluation. Show `src/features/evidence-coach/evidence-coach.ts` and explain that it uses the official OpenAI SDK, GPT-5.6 Responses API, `responses.parse`, and a Zod output schema on the server only. Mention the tested no-key fallback.

## 2:35–2:40 — Close

Say: “Don’t just use AI. Learn to test it.” Include spoken credit: “Glassbox was built with Codex, and GPT-5.6 is used as the constrained Evidence Coach.”

Before publishing, confirm the video is public or unlisted, under three minutes, includes voiceover, and can be watched while logged out.
